SCARPERM

Android permission explainer. Rates permissions from names or a decoded AndroidManifest.xml and says why each one matters.

GitHub ↗All tools

Quick start

scarperm READ_SMS CAMERAscarperm -m AndroidManifest.xml --json
Authorized use only. Run it only on systems and data you own or have written permission to test.

What it does

  • Around 35 common Android permissions rated info, low, medium or high
  • A one-line reason for each permission
  • Reads permissions from a decoded AndroidManifest.xml
  • Exit code 1 when a high-risk permission is present
