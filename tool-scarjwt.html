SCARJWT

JSON Web Token decoder and auditor. Flags alg none, missing expiry, risky headers and sensitive claims, and checks HMAC signatures. Offline.

GitHub ↗All tools

Quick start

scarjwt decode TOKENscarjwt audit TOKENscarjwt verify TOKEN --secret KEY
Authorized use only. Run it only on systems and data you own or have written permission to test.

What it does

  • Decodes header and payload without any network call
  • Flags alg none, empty signature, missing exp, long lifetimes and jku/x5u headers
  • Warns about sensitive-looking claims in the readable payload
  • Verifies HS256, HS384 and HS512 signatures against a secret you provide
