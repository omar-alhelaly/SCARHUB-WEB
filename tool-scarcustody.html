SCARCUSTODY

Evidence hashing with a tamper-evident chain-of-custody log. Each entry holds the hash of the previous one, so edits break the chain.

Private repositoryAll tools

Quick start

scarcustody init --name CASE-042 --actor "Omar"scarcustody add /mnt/usb/image.dd -n "seized from desk 3"scarcustody verify --record
Authorized use only. Run it only on systems and data you own or have written permission to test.

Related tools

SCARLOG

Log analyzer for forensics and defense. Reads SSH/auth and web access logs, builds one timeline and reports observations such as brute force and probe paths.

SCARIOC

Indicator of Compromise extractor. Pulls IPs, domains, URLs, emails, hashes and CVEs from logs and reports. Understands defanged input. Offline, stdlib only.

SCARTIME

Timestamp converter and log timeline merger. Understands Unix seconds, ms and us, Windows FILETIME, ISO 8601, syslog and web access log formats.

SCARMETA

File identifier. Detects the real type from magic bytes, flags extension mismatches and high-entropy (packed or encrypted) content.

SCARHASH

Hash files and verify sha256sum-style checksum lists. Reports OK, FAILED and MISSING for each file.
