SCARLIST

Markdown checklists for engagements. Web, network and DFIR templates, tick items off and see progress. Exit code 1 while work remains.

GitHub ↗All tools

Quick start

scarlist init engagement.md --template webscarlist done engagement.md 3scarlist show engagement.md
Authorized use only. Run it only on systems and data you own or have written permission to test.

What it does

  • Web, network and DFIR checklist templates
  • Plain markdown files you can keep in git
  • Tick and untick items by number
  • Shows progress and exits 1 while items remain
